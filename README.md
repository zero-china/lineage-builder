# lineage-builder

Automated LineageOS 18.1 builder for Samsung S9+ (star2qltechn) via GitHub Actions.

## Usage
1. Go to Actions tab
2. Select "Build LineageOS 18.1 for Samsung S9+ (star2qltechn)"
3. Click Run workflow -> Run workflow
4. Download artifact `LineageOS-18.1-star2qltechn-ROM` after build completes (2-4h)
